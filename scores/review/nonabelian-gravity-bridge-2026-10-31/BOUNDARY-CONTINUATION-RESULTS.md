## Matched computation on an older solved question

boundary-benchmark-root.py compares two ways of compiling the very same
native80-input quadratic cut density to all6400 exact rational Hessian
entries. Dense scalar polarization uses3240 density evaluations; sparse
symbolic expansion uses one polynomial density expansion with204 nonzero
monomials. Every coefficient agrees with the approved source matrices.

In the recorded single run the dense method took8.48054seconds and the
sparse method0.013633seconds. Both timings include matrix construction,
exclude shared definitions/output checks, and use the same scalar source.
This is a comparison with a naive dense polarization baseline, not an
optimized solver survey. It times quadratic Hessian compilation, not
execution of the relation-valued score or full affine boundary momentum
evaluation. The original linear boundary term has zero Hessian. Host
load, fixed order and single-sample timing limit the observation; no
general speedup theorem or physical simulation speedup is asserted.
